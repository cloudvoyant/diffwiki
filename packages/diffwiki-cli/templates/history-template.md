## Raw harness session and artifacts

Not captured. Record the harness name, raw session transcript path, and relative links to verbatim session logs or artifacts stored under `.meta/attachments/<record-id>/`.

## Raw user requests

Not captured. Include exact quotations, speaker, original time, and session/message location when known.

## Stated rationale

Not captured. Quote the user's explanation. Do not infer a reason.

## Human review and plan feedback (.difflab)

Not captured. Include verbatim human reviewer comments, `.difflab/plans/*/revisions/*.md` (`## Feedback`), and `.difflab/reviews/*/REVIEW.md` findings with file/revision locators.

## Raw session/tool outputs

Not captured. Include the command, output, exit status, and source location. Label assistant text as generated and unverified.

## Source snippets

Not captured. Preserve code and whitespace. Include repository, file, symbol/lines, commit when known, and local changes.

## Source record links

None captured. Link any shared collection evidence, attachments, or earlier records.

## Change and result

Not captured. Name affected files and the observed result. Keep capture time separate from the original event time.
