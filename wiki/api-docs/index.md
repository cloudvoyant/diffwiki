# API Docs

Reference for building on diffwiki. Everything here is grounded in the real CLI command surface and the `diffwiki-core` public API — every command, flag, and export documented below exists in the source.

- [CLI Reference](/api-docs/cli) — every `diffwiki` command, option, and default.
- [diffwiki-core](/api-docs/core) — the host-side TypeScript API the CLI and wiki app share.
- [Plugin SDK](/api-docs/plugins) — the subprocess wire protocol and `definePlugin` authoring SDK for search plugins.
